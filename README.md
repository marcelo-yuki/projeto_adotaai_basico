# Adota Aí — Fase 1

Reorganização da versão atualizada do protótipo, preservando HTML, CSS, JavaScript e Tailwind CDN.

## Executar

Abra a pasta `client` com um servidor HTTP local (por exemplo `py -m http.server 8000` dentro dela) e acesse http://localhost:8000.

## Estrutura

- `client/`: interface atual
- `server/`: reservado para a API em JavaScript puro
- `database/`: reservado para scripts PostgreSQL

Nesta fase não há API ou banco de dados. A autenticação e os dados locais do protótipo não são adequados para produção.
